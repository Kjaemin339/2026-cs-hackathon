# 디자인 결정

컴퓨터학부 학생이 처음 들어와도 직무를 고르고 바로 체험할 수 있는 작은 작업실을 목표로 합니다.

- 흰색 바탕, 진한 회색 글자, 파란색 주요 행동을 사용합니다. 역할별 색상은 미리보기에서만 구분합니다.
- 첫 화면은 직무 선택에 집중합니다. 큰 소개 배너와 반복 설명, 시작 전 설문을 제거했습니다.
- 역할 카드는 각각 화면, 요청 흐름, 막대 차트, 검색 결과, 접근 권한, 배포 지표를 보여줍니다. 외부 제품 이미지를 복제하지 않고 직접 구성했습니다.
- 체험 화면은 해야 할 조건과 코드, 실행 결과를 함께 보여줍니다. 진행 순서와 다음 행동을 명시합니다.
- AI는 함께 풀기 영역에 배치합니다. 과제 조건 확인 → 필요한 자료 확인 → 다음 행동 제안의 실제 활동을 보여주며, 가짜 다중 에이전트나 완료 상태를 만들지 않습니다.
- 모바일에서는 직무 카드가 작은 가로 목록으로 바뀝니다. 키보드 초점, 대화상자 초점 이동, 줄어든 모션을 지원합니다.

## 참고

- [Codecademy 카탈로그](https://www.codecademy.com/catalog): 분야별 탐색과 짧은 학습 단위
- [solved.ac](https://solved.ac/en): 과제 탐색과 진행 상태를 분리한 구성
- [Linear](https://linear.app/features): 작업 영역과 보조 정보의 위계
- [WEF Future of Jobs 2025](https://www.weforum.org/publications/the-future-of-jobs-report-2025/): AI·데이터와 네트워크·보안 분야 확장 참고. 특정 직무의 취업 가능성이나 적성 보장을 의미하지 않습니다.
